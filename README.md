# 교보 eBook 리눅스 웹뷰어 (교보문고앱만들기)

교보문고 eBook 및 학교/지자체 전자도서관 공식 웹뷰어를 리눅스 네이티브 앱처럼 사용하기 위한 GTK3 + WebKit2 래퍼입니다.

## 주요 기능
- **홈 대시보드**: 교보문고 eBook, 내 서재, 전자도서관, sam 바로가기 + 사용자 도서관 북마크 추가(`~/.config/kyobo-webviewer/bookmarks.json`)
- **로그인 유지**: 영구 쿠키 + 세션 쿠키 자동 백업/복원(`~/.local/share/kyobo-webviewer/`) 및 ITP 비활성화
- **독서 전용 팝업 창**: 전자도서관 `[바로보기]` 및 소셜 로그인 팝업 지원
- **독서 색상 필터**: 기본 / 세피아 / 저조도 / 다크 모드 지원
- **Chrome 앱 폴백**: 특정 웹뷰어가 Chrome 전용 스크립트를 요구할 경우 상단 **Chrome 앱** 버튼으로 독립 Chrome 앱 창 실행

## 설치 및 실행
```bash
bash install.sh
kyobo-webviewer
```
설치 후 리눅스 앱 런처에서도 **교보 eBook 웹뷰어**로 바로 실행할 수 있습니다.

## 단축키
- `F11`: 전체 화면 전환
- `Ctrl + B`: 상단 툴바 숨김/표시 (집중 독서 모드)
- `Ctrl + L`: 주소창 포커스
- `Ctrl + +` / `Ctrl + -` / `Ctrl + 0`: 화면 확대 / 축소 / 초기화
- `Alt + ←` / `Alt + →`: 뒤로 / 앞으로
- `F5`: 새로고침
